# Optional project tools

The four notebooks contain the acquisition, cleaning, feature engineering, training and evaluation code. They import no project helper scripts.

| Tool | Purpose |
|---|---|
| `run_simple_notebooks.py` | Run notebooks 01–04 in fresh kernels |
| `verify_simple_reproduction.py` | Compare current outputs with the compact original-results reference |
| `audit_raw_data.py` | Audit raw source structure and 2025 source counts |

The old experiment-export, setup-publishing and report-building scripts have been removed.
